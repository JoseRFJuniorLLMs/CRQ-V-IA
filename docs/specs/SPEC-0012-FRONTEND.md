# SPEC-0012 — Frontend e experiência do usuário

## Diretriz

A aplicação deve funcionar como instrumento de fiscalização, não como CRM genérico.

## Tela de busca

Layout em três áreas:

1. filtros à esquerda;
2. resultado central;
3. resumo da seleção/contagens no topo.

Cada linha exibe:

- empresa;
- CNPJ;
- município;
- CNAE principal;
- porte;
- situação cadastral;
- score;
- selo de motivo regulatório;
- última atualização.

## Perfil de empresa

Seções:

- Identificação.
- Situação cadastral.
- Atividades econômicas.
- Fatores de prospecção.
- Histórico da base.
- Estado interno CRQ-V.
- Verificação oficial on-demand.
- Ações: adicionar à lista, exportar, registrar nota.

## Acessibilidade

- WCAG 2.1 AA como alvo.
- navegação por teclado.
- contraste adequado.
- labels explícitos.
- sem depender apenas de cor para score.

## Responsividade

Desktop é prioridade, mas telas críticas devem funcionar em tablet.
